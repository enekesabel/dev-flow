# Glossary

| Term | Definition | Source |
| --- | --- | --- |
| DevFlow | The umbrella project and work domain. It includes DevFlow development and the DevFlow skill. | user source |
| DevFlow development | The work of developing, dogfooding, evaluating, and supporting the DevFlow skill. It includes project tooling and the development record. | user source |
| DevFlow skill | The current product under development: the always-on skill that applies DevFlow's intent-alignment rules during agent work. | user source |
| Project tooling | Repository instructions, Grove and MCP configuration, and supporting tools used to develop and test DevFlow. It is not part of the DevFlow skill by default. | user source |
| Skill adoption | The project-local process of turning a conclusion from DevFlow development into DevFlow skill behavior through an accepted Decision followed by Work. | user source |
| DevFlow development record | The durable record of Decisions, Questions, Assumptions, and Discoveries from DevFlow development. Grove stores this record. | user source |
| Grove | The underlying layer for storing project reasoning, relationships, evidence, and durable knowledge. | user source |
| User intent | What the user wants the project or future deliverable to achieve or preserve. | user source |
